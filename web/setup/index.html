Connect a Google Sheet

Run Homebound serverless using your own Google Sheet as the database.

5-Step Setup

1
Make a new Google Sheet

Open Google Sheets and create a blank spreadsheet for your event.

2
Open Apps Script & Paste Code

In your Sheet, click Extensions → Apps Script, replace any existing code with the Homebound backend script, and save.

Copied to clipboard!
3
Run setup

Select setup in the function dropdown and click Run (grant permissions when asked). An alert will show your Admin PIN and Monitor Code.

4
Deploy as Web App

Click Deploy → New deployment. Select type Web app, set Execute as: Me and Who has access: Anyone. Copy the Web app URL.

5
Paste the URL below
