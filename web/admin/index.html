Connect Luma API

Sync guest list directly from your Luma event

ℹ️ Where to find your Luma API Key & Event ID

  1. Log into your host account on lu.ma.
  2. Go to Settings (click your avatar at top-right) → API (or visit lu.ma/settings/api).
  3. Click Create API Key, choose a label (e.g. Homebound), and copy the key (begins with luma_api_...).
  4. Open your event's management page: the Event API ID is in the URL or under Event Settings → API (format: evt-...).

🔒 Encrypted: Your API key is encrypted with AES-256 on the server and is never stored in plaintext.
